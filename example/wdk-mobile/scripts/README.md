# scripts/

## `fix-ios-durability.sh`

Reapplies three iOS build fixes that live outside version control and so
regress whenever their trigger fires. Idempotent -- every step checks its
own precondition and no-ops if already applied.

```sh
./scripts/fix-ios-durability.sh
```

### Steps

1. **Patch `Wavewalletdk.xcframework` headers** (`@import Foundation;` ->
   `#import <Foundation/Foundation.h>`), via
   `wavelength-bindings/ios/patches/fix-wavewalletdk-headers.sh`. The
   xcframework is patched in place, so re-fetching it reverts the fix and the
   build fails with a Clang error.

2. **Ensure `ios/Podfile` vendors `wavelength-bare-addon`.** `ios/` is
   gitignored and regenerated by `expo prebuild`, which drops the `pod` line.
   Without it nothing embeds `Wavewalletdk.xcframework` or propagates
   `-lresolv`, so the app either fails to link or segfaults the first time
   the addon calls into Wavewalletdk.

3. **Rebuild `worklet/driver-wdk.bundle.js`** from `driver-wdk.mjs` via
   `bare-pack --host ios --linked`. Nothing regenerates this bundle
   automatically, so changes to `wdk-wallet-wavelength` leave the app running
   stale code.

### Run it after

- `npx expo prebuild` (step 2)
- Any change to `wdk-wallet-wavelength`'s source (step 3)
- Any re-fetch of `Wavewalletdk.xcframework` (step 1)

### Not covered

Does not touch `node_modules` or run `pod install`/`xcodebuild`. Run
`cd ios && pod install` afterward if step 2 inserted the pod line.
