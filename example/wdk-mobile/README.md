# Wavelength WDK Mobile App

Wavelength/WDK wallet demo running on React Native

<p align="center">
  <img src="./docs/screenshot.png" alt="wdk-mobile app screenshot" width="300" />
</p>

## Usage

```sh
npm install
```

### iOS

```sh
npm run ios
```

If this is a fresh `expo prebuild` (or the native addon/xcframework was
re-staged), run `./scripts/fix-ios-durability.sh` first -- see
[`scripts/README.md`](./scripts/README.md) for what it fixes and why.

### Android

```sh
npm run android
```
